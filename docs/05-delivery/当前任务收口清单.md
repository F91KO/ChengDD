## Spring Cloud Alibaba + Nacos 收口状态

- 已完成：
  - Spring Boot `3.5.14`、Spring Cloud `2025.0.3`、Spring Cloud Alibaba `2025.0.0.0`、Nacos Client `3.0.3` 版本收敛。
  - `cdd-common-nacos` 适配边界；十个可执行模块使用官方 Config/Discovery，其他模块不直接依赖 Nacos Client。
  - `{env},file` / `{env},nacos` profile，先共享后服务的 Config Data 导入，`refreshEnabled=false`。
  - Gateway Spring Cloud LoadBalancer 服务发现与 file/无实例静态地址回退。
  - Nacos `3.0.3` 本地 Compose、v3 liveness、配置发布、注册检查和十服务安全启停脚本。
  - Liquibase `4.31.1` classpath 迁移资产打包兼容。
  - 真实 Nacos 集成契约及 Task 8 全链路功能验收。
- 已知缺陷：
  - 十个 Nacos 模式服务在成功注销后均记录 `NacosGracefulShutdownDelegate` ERROR/NPE；未影响退出、端口清理或注册清空，仍需后续兼容性修复。
- 待完成：
  - 生产 Nacos 集群与高可用部署。
  - Nacos 鉴权、权限、TLS 和凭据轮换。
  - Nginx/HTTPS 接入。
  - CI/CD 中的真实基础设施集成与部署流水线。

本地 Compose 的 Nacos 为 standalone 且关闭鉴权，仅供开发和验收，不得直接作为生产配置。
